## ✨ المميزات الرئيسية

- 🧠 **ذكاء اصطناعي متقدم (White Room AI)**:  
  يعتمد على خوارزمية `Minimax` مع `Alpha-Beta Pruning` و `Quiescence Search` بعمق يصل إلى 5 مستويات، مع حد زمني صارم (أقل من 4 ثوانٍ) لضمان سرعة وقوة اللعب (مستوى 2200-2600 ELO).

- 🎨 **واجهة مستخدم فاخرة (Glassmorphism)**:  
  تصميم زجاجي شفاف وأنيق، مع بروفايل تفاعلي لأيانوكوجي يحتوي على مؤشر تفكير (نقاط متحركة) ومؤشر صوتي (خطوط متحركة) يظهر فقط عند تحدثه.

- 🎬 **شاشات بداية ونهاية ديناميكية**:  
  - شاشة بداية تفاعلية مع بيدة يتغير لونه عشوائياً.
  - شاشة اختيار اللون (أبيض/أسود) مع قلب الرقعة تلقائياً.
  - شاشات نهاية مخصصة مع اقتباسات فريدة تتغير حسب النتيجة (فوز، تعادل، أو خسارة).

- 🔊 **نظام صوتي غامر ومتوازن**:  
  - موسيقى خلفية هادئة تساعد على التركيز (مستوى 20%).
  - صوت حركات قطع دقيق وخفيف (مستوى 20%).
  - صوت خاص لأيانوكوجي يظهر **فقط عند حركته الأولى** في كل مباراة مع تأثير بصري متزامن (مستوى 35%).

- 📱 **تصميم متجاوب بالكامل**:  
  يعمل بسلاسة تامة على جميع الأجهزة (حواسيب، أجهزة لوحية، وهواتف ذكية).

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية**: HTML5, CSS3 (Glassmorphism, Animations), JavaScript (ES6+)
- **المكتبات**: jQuery, Chess.js (منطق اللعبة), Chessboard.js (عرض الرقعة)
- **الصوت**: Web Audio API (لتوليد المؤثرات الصوتية ديناميكياً)
